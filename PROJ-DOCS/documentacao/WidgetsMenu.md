# Widgets Documentation — Introduction

This documentation provides a concise, practical reference for all UI widgets made by the team of this project. 
It describes purpose, behaviour, theming options and implementation notes for each widget.

## Audience
- Developers: Integration.
- Designers: Usage.
- QA: expected behaviour and test cases.

## Scope
- All built-in widgets and their supported variants or addons.
- Integration snippets, configuration options and examples.

## Documentation structure
Each widget page follows the same structure:
1. Overview — purpose and common use cases.
2. Examples — minimal and real-world snippets.
3. Theming & Styling — How to style each widget.
   

## How to use this documentation
- Start at the Overview for recommended patterns.
- Copy example snippets to the local environment and adapt props.
